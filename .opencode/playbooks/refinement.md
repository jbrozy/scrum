# Playbook: Backlog Refinement (Scrum Master facilitates) — `Phase: refinement`

Goal: enough ready items for the next sprint (about 2× capacity).

1. Resume the PO: `PHASE: refinement-draft`, CONTEXT = capacity of this sprint and the Review coming up.
   The PO returns the story ids that need developer input.
2. Pick the two developers whose focus areas fit those stories best. Call both in ONE message (resumed):
   `PHASE: refinement`, CONTEXT = the story ids.
3. Resume the PO: `PHASE: refinement-final`, CONTEXT = both developers' REPORT lines verbatim.
4. Write `scrum/sprints/sprint-NN/refinement.md`: stories refined, estimates, splits, items now `ready`, open risks.
5. Commit: `git add -A && git commit -m "scrum(sprint-NN): refinement"`.
