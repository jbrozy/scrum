# Working Agreements

> Loaded into every agent's context. Only the Sprint Retrospective changes this file (the Scrum Master records the decisions). Keep it under ~60 lines — retire old agreements to `scrum/agreements-archive.md`.

## Parameters

| parameter | value | allowed range |
|---|---|---|
| days_per_sprint | 3 | 2–5 |
| wip_limit_per_dev | 1 | 1–2 |
| max_story_points | 5 | 3–8 |
| required_approvals | 1 | 1–2 |
| capacity_buffer_percent | 20 | 0–40 |
| review_routing | focus-match | focus-match, round-robin |
| direct_calls_per_block | 1 | 0–2 |

## Active agreements

None yet — the first Retrospective adds them.

## Format

```
### WA-NN · <short title>
- Problem (evidence): <what went wrong, with numbers/files>
- Change: <what we do differently>
- Applies to: <roles or members>
- Owner: <who watches it>
- Success signal: <measurable check>
- Since: sprint-NN · Check in: sprint-NN
```
